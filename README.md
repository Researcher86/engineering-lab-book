# Книга PHP Systems Lab

Учебник по устройству backend-инфраструктуры, написанный по коду лаборатории.
Каждая глава разбирает один механизм на настоящем коде одного из проектов, со
ссылками на файлы и строки, и даёт эксперимент, который можно запустить у себя.

Это не пересказ README проектов. README отвечают на вопрос «что здесь есть», а
книга — на вопрос «как это работает и почему так».

## Как читать

Главы выстроены в том же порядке, что и уровни лаборатории: каждая опирается на
предыдущие. Если механизм уже знаком, главу можно пропустить. Ссылки «→ глава N»
показывают, где механизм разбирается.

Стандартная глава устроена так:

1. **Проблема** — зачем механизм нужен и что ломается без него.
2. **Устройство** — как он работает, со схемой.
3. **Код** — выдержки из настоящих файлов, каждая со ссылкой на строки.
4. **Эксперимент** — что запустить, чтобы увидеть механизм живым.
5. **Отказы** — что ломается и как проект это ловит.
6. **Как это проверено** — какие тесты стоят на страже и почему им можно верить.
7. **Цифры** — числа, на которые опираются утверждения.
8. **Упражнения** — задачи на понимание и на расчёт.

После этого идёт «Что дальше» — соседние главы и связь с остальной книгой. В
главах 03 и 20 код встроен в тематические разделы, а в главе 04 есть отдельный
раздел о терминологии; поэтому нумерация разделов там отличается.

### Ссылки на код

Ссылки ведут на GitHub и привязаны к **тегу релиза или полному SHA коммита**, а
не к ветке `master`. Поэтому номера строк в ссылке и строки в выдержке всегда
совпадают, даже когда код в проекте меняется. У `php-memory-lab`,
`php-concurrency` и `php-systems-platform` тегов нет — для них используется SHA.
Чтобы посмотреть ту же версию локально:

```bash
git -C php-mini-search checkout v1.0.0
git -C php-memory-lab checkout 7c8d365692bcc8756653695b88a62d3412128b88
```

Выдержки скопированы из файлов как есть, вместе с комментариями. Комментарии в
коде лаборатории на английском и объясняют каждое решение, поэтому их стоит
читать.

### Эксперименты

Все эксперименты запускаются в Docker-контейнере проекта, на хост ничего
устанавливать не нужно:

```bash
cd php-mini-search
make build install      # один раз
make shell              # оболочка внутри контейнера
```

Вывод в главах — это реальный вывод, снятый при написании главы.
